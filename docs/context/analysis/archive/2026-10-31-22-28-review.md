# L0 operational census

**Scope:** the 11 ratified L0 cells (`specs/L0-match/00`-`10`) against the code in `crates/`. What the spec promises, what the code does, where they diverge. Every entry cites `file:line` on both sides.

**How to read it:** a gap is not a bug report. It is a difference between a ratified contract and the current prototype. Some are accepted (L0 is a prototype); some are doctrinal (G2, G10 touch Plane A); some are simply unimplemented (G5, G6, G7).

**Snapshot:** `246f64b`. This report ages: when L0 changes, archive it and write a new one. Do not update it in place.

## 1. Summary

- **11 cells ratified** (`00-overview.md:19`), checklist at `00-overview.md:85` not complete.
- **12 divergences** found: 5 high, 5 medium, 2 low.
- **The largest:** 4 `EventType` emitted out of 27 (G11), and the attempt/outcome two-phase model absent from code (G5).
- **Two touch the doctrine** (Plane A / determinism): G2 (panic isolation) and G10 (public getters on `GroundTruth`).

## 2. Divergences

### G1 — RNG streams without `match_id` (high)

- Spec: `match:{match_id}:micro-decisions`, `:random-events`, `:set-pieces` (`specs/L0-match/01-rng.md:66-68`). The spec warns explicitly: "if cells have names like match:decisions (no match_id), they collide" (`:78`).
- Code: `match:actions`, `match:action_kind`, `match:player_pick` (`crates/pcfm-match/src/state.rs:54-58`). The doc comment admits the limitation (`state.rs:43-44`).
- Effect: two matches with the same world seed start the engine streams identically. Deterministic, but not per-match.

### G2 — Event bus handler panics propagate (high)

- Spec: caught at the handler boundary, logged, the event marked `failed`, the match continues (`specs/L0-match/02-event-bus.md:108`).
- Code: the panic propagates and drains events are lost (`crates/pcfm-core/src/event_bus.rs:81-85`). Documented as a known limitation.
- Doctrinal: a panicking handler can take down a match. D2 (no panic in simulation paths) applies.

### G3 — `condition` out of range: clamp vs reject (low)

- Spec: clamp on construction, log a warning (`specs/L0-match/03-entities-minimal.md:189`).
- Code: `Pitch::try_new` rejects an out-of-range condition (`crates/pcfm-model/src/pitch.rs:56-60`).
- Effect: a spec-sanctioned input is refused. Low impact, but the contract differs.

### G4 — `MatchContext` lacks `bus` and `modifiers` (medium)

- Spec: `pub bus: &mut EventBus`, `pub modifiers: ContextModifiers` (`specs/L0-match/04-match-engine.md:55-60`).
- Code: `match_`, `hidden`, `rng`, `chain`, `config` only (`crates/pcfm-match/src/context.rs:47-57`).
- Effect: the engine cannot use the event bus or context modifiers through the declared interface.

### G5 — Attempt/outcome two-phase events absent (high)

- Spec: `PassAttempted`, `ShotAttempted`, `DuelStarted`, `FoulCommitted`, each with a `position_snapshot`, the outcome linked via `attempt_event_id` (`specs/L0-match/05-match-events.md:61-73,128`).
- Code: zero occurrences of `Attempted`, `attempt_event_id`, `PositionSnapshot` in `crates/`.
- Effect: `ARCHITECTURE.md:124` and `CODE_TOUR.md:143` describe this as current behaviour. It is not.

### G6 — `compute_rating` does not exist (medium)

- Spec: `compute_rating(player_id, events, config)`, computed from events only (`specs/L0-match/06-match-output.md:58`).
- Code: no `compute_rating`, no `RatingConfig`. Ratings are not produced.
- Effect: L2 (ratings, scouting) has no foundation.

### G7 — No `command_log`, JSON not postcard (medium)

- Spec: `command_log: Vec<Command>` for replay, postcard serialisation (`specs/L0-match/07-save-minimal.md:60-71`).
- Code: no `command_log`; save uses `serde_json` (`crates/pcfm-match/src/save.rs:131,142-143`).
- Effect: replay works by re-simulating, not by replaying a command log. Different contract, same observable result today.

### G8 — Random event catalogue absent (medium)

- Spec: `RandomEventDef` in `balance/random_events.toml` (`specs/L0-match/08-random-events.md:64`).
- Code: `balance/` does not exist; zero integration in the engine. `RandomEvent` appears only in `narrative.rs:107,156`.
- Effect: L0.08 is a specification with no implementation.

### G9 — `ContextModifiers` absent (medium)

- Spec: a clean struct through which external state enters the engine, never reading L2/L1 directly (`specs/L0-match/09-context-modifiers.md:31,48`).
- Code: zero occurrences in `crates/pcfm-match/`.
- Effect: the engine has no channel for external context.

### G10 — Public getters on `GroundTruth` (medium, doctrinal)

- Spec: only `new`, `resolve_*`, `drain_observations` are public; `Debug` prints `GroundTruth { .. }` (`specs/L0-match/10-ground-truth.md:75,106-111`).
- Code: `world_seed()` and `match_id()` are public (`crates/pcfm-hidden/src/lib.rs:81,87`); `Debug` prints both fields.
- Effect: not a latent leak (they are non-latent identifiers), but the declared API surface differs. The strict contract is broken.

### G11 — 4 event types emitted out of 27 (high)

- Spec: `EventType` has 27 variants (`crates/pcfm-stats/src/event.rs`).
- Code: `state.rs` emits only `Shot`, `Goal`, `Duel`, `Foul`. Pass, tackle, save, set piece, pressure, injury are resolved by `resolve_*` but never recorded as events.
- Effect: a defender and a goalkeeper produce no events. L2 (ratings) has almost nothing to read. This is the largest single gap.

### G12 — "Ratified" vs checklist (medium, ambiguity)

- `00-overview.md:19` says all 11 cells are ratified; `:85` says the seven-point checklist is the acceptance test, and it is not complete.
- Reading: "ratified" means the *contract* is accepted, not that the code implements it. The distinction is stated in the overview, but easy to miss alongside `ARCHITECTURE.md` prose that describes unimplemented behaviour as current.

## 5. Verdict

L0's **contract** is ratified and the **prototype** implements a subset of it. The subset is enough for L1 (score, scorers); it is not enough for L2 (ratings need events per player). The gap is declared, not hidden: OI-13 and this report say what is missing.

Next decision (not taken here): which gaps to close before L1, and which before L2. That is a design choice, tracked in OI-17.
